# JACK22 11.5 + Claude — réponse au bilan « prochain lot »

Base : `JACK22-11.5-CLAUDE-MAQUETTES-CANDIDATE.zip`, comme demandé. Le fichier de ChatGPT n'est pas retouché à la main. Les changements passent par les blocs de Claude ajoutés en fin de fichier, plus quelques retouches de valeurs contrôlées par le script d'assemblage. Le design validé est gardé :
- un seul clavier vert horizontal sous le Piano Roll ;
- Samples à droite ;
- trois colonnes dans Voix.

## 1. Studio : premier parcours évident

- **Bande « Premiers pas »** sous la barre des espaces, seulement dans Studio : **① Créer un beat → ② Enregistrer une voix → ③ Garder ton travail**.
- **Chaque étape a son bouton,** qui mène à une commande existante :
  - « Ouvrir la batterie » ;
  - « Ouvrir les prises » ;
  - « Sauvegarder le projet » et « Exporter le morceau (WAV) ».
- **Les étapes se cochent seules :**
  - ① dès qu'un pattern de batterie a un pas ;
  - ② dès qu'une voix est enregistrée ;
  - ③ quand le projet est sauvegardé (plus de ● sur Sauvegarder).
  - La prochaine étape est en rouge.
- **La bande se masque avec ×** et revient par Projet ▾ → « Premiers pas ». Les réglages avancés restent où ils étaient.

## 2. Voix : état du micro

Dans la colonne Micro & réglages :
- **le micro choisi** (liste) ;
- **l'autorisation :** accordée, refusée ou à demander (lue dans le navigateur, mise à jour quand elle change) ;
- **le voyant** « ● Micro actif » (rouge, clignotant) ou « Micro coupé ». Il s'allume pendant une prise et pendant un test de niveau ;
- **« Tester le niveau »** ouvre le micro choisi sans enregistrer : la barre Niveau d'entrée bouge ;
- **« Couper le micro »** le referme. Le micro de test se referme aussi tout seul si on quitte l'écran Voix. Le micro d'une prise n'est jamais coupé d'ici ;
- **si l'accès est refusé,** une aide en rouge s'affiche : cadenas à gauche de l'adresse → Microphone → Autoriser, puis recharger ; sinon, réglages Windows → Confidentialité → Microphone ;
- **l'état de la prise** à côté de REC / STOP : Prêt, Décompte… ou ● Enregistrement ; le chrono passe en rouge.

Le bouton « Autoriser le micro » de la 11.5 (qui ouvrait puis refermait aussitôt) est remplacé par « Tester le niveau », qui fait la même demande et montre le niveau.

## 3. Sauvegarder le projet ≠ Exporter le morceau (WAV)

- **En-tête de Studio :**
  - « Sauvegarder » explique, au survol, qu'il sert à rouvrir et continuer, et que ce n'est pas un fichier audio ;
  - nouveau bouton **« Exporter le morceau (WAV) »** juste à côté ;
  - « Exporter projet » devient **« Copie (.zip) »**, avec l'explication : fichier du projet pour un autre ordinateur, pas un morceau à écouter.
- **Barre du bas** (hors Studio) : « Exporter WAV » à côté de « Sauvegarder ».
- **L'export WAV part d'un clic, depuis n'importe quel écran.** Un message dit que le fichier arrive dans Téléchargements.
- **Réouverture et remplacement d'une prise avec Annuler : vérifiés** (voir plus bas).

## 4. Design

Le design validé n'a pas changé. Captures dans `captures/`, à comparer aux deux maquettes : Composition (Piano Roll) et Prises voix.

## 5. Confiance : ce qui reste local

- **Rien n'est transmis.** Le fichier HTML ne contient **aucun** appel réseau : ni `fetch`, ni `XMLHttpRequest`, ni `sendBeacon`, ni WebSocket, ni adresse `http(s)://`.
- **Projets et prises restent dans le navigateur de l'ordinateur** (localStorage et IndexedDB). Ils ne sortent que par une action de l'utilisateur : export WAV, copie .zip ou WAV brut, enregistrés dans Téléchargements.
- **Seule exception technique :** la version « web » installable utilise un *service worker* (`sw.js`) pour fonctionner hors connexion. Il ne fait que mettre en cache les fichiers du studio et n'envoie rien.
- **Aucun avertissement à afficher pour l'instant,** puisqu'il n'y a aucune transmission. Si une fonction en ligne est ajoutée un jour, il faudra prévenir avant tout envoi de prise.
- **Sons fournis :** le fichier ne contient **aucun fichier son** (pas de `data:audio`, pas de WAV ni de MP3 intégrés). Batterie, synthé, 808, guitare et voix de démo sont **fabriqués par le code**. Il n'y a donc pas de licence de samples tiers à vérifier aujourd'hui. Les sons importés par l'utilisateur (WAV, MP3) restent sous sa responsabilité.
